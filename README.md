## 🤖 Bots para Telegram

Um conjunto de 3 bots independentes para Telegram, com funcionalidades voltadas para gerenciamento, sorteio e apostas esportivas.

- **Bot de Gerenciamento de Grupo:** moderação, boas-vindas automáticas, filtro de spam e comandos administrativos.  
- **Bot de Sorteio:** sorteios rápidos e fáceis dentro do chat.  
- **Bot de Aposta Esportiva:** sistema de apostas, pontuação e ranking integrado com APIs de resultados esportivos.  

**Tecnologias:** Python, `python-telegram-bot`

🔗 [Repositório dos Bots Telegram](https://github.com/usuario/telegram-bots)

## 🛡 Cyberflix — Portal de Cibersegurança

Site informativo que organiza diversas ferramentas de cibersegurança divididas em três categorias:  
- 🔴 Red Team (ataque)  
- 🔵 Blue Team (defesa)  
- 🟠 OSINT (coleta de informações)  

Permite navegar por ferramentas, acessar páginas dedicadas e baixar diretamente os softwares. Também inclui links para baixar Kali Linux e VirtualBox.

**Tecnologias:** HTML, CSS, JavaScript
